# RAINY-CONNECT — Монголын нэгдсэн мэдээллийн хайлт
Огноо: 2026-10-12
Төлөв: Хэрэглэгчийн бичгээр хянах загвар. Хэрэгжүүлэлт эхлээгүй.

## 1. Зорилго, батлагдсан хүрээ
Монголд ашиглах боломжтой хууль, дүрэм, тогтоол, тушаал, нийтийн баримт бичиг, статистик, нээлттэй өгөгдлийг нэг системийн нэг хайлтаар олж, шүүж, эх файлыг татдаг платформ. Хэрэглэгч энэ хүрээг баталсан.
Хамрах хүрээ нь бүртгэсэн, холболт нь шалгагдсан, ашиглах эрхтэй эх сурвалжууд байна. Монголын бүх баримтыг бүрэн хамарсан гэсэн баталгаагүй мэдэгдэл гаргахгүй.

## 2. Хэрэглэгчийн урсгал
Хайх үгээ бичих → үр дүн болон хамарсан эх сурвалжуудыг харах → төрөл, байгууллага, огноо, төлөв, газар нутаг, файлын төрлөөр шүүх → агуулгыг үзэх → эх холбоос нээх эсвэл файлыг татах.
Нэвтрэхгүйгээр нийтийн хайлт ашиглана. Байгууллагын дотоод файл, хадгалсан хайлт, webhook, админ үйлдэлд нэвтэрнэ.
Монгол хэл үндсэн; англи интерфейс нэмэх боломжтой. Гэгээлэг, цэвэр UI, гар утсанд зохицсон.

## 3. Эх сурвалжийн хамрах хүрээ
### Шалгагдсан баримтжуулалт
- ҮСХ: https://opendata.1212.mn/mn/doc болон https://www.1212.mn/mn/data-base/open-data
  Статистикийн API байна. Хуучин API болон PxWeb интерфейсийн бодит ажиллагааг тусад нь шалгаж идэвхжүүлнэ.
- Legalinfo: https://legalinfo.mn/mn
  Хууль, олон улсын гэрээ, зарлиг, УИХ/ЗГ тогтоол, тушаал, орон нутгийн актын нийтийн каталог байна.
  Нээлттэй API баталгаажаагүй. Автомат импорт, хадгалалт, дахин түгээлтийн нөхцөлийг шалгахаас өмнө зөвхөн эх сурвалжийн холбоос бүхий каталог хэлбэрээр бүртгэнэ.
- Төрийн нээлттэй өгөгдөл: https://opendata.gov.mn/
  Портал баталгаажсан; нийтэд дэмжигдэх API болон файл таталтын маршрутыг интеграцийн үед шалгана.

### Дараагийн холболтод үнэлэх эх сурвалж
tender.gov.mn, shilendans.gov.mn, parliament.mn, gov.mn, shuukh.mn, mongolbank.mn,
яам/агентлаг/аймаг/нийслэлийн албан ёсны сайтууд.
Эдгээр нь одоогоор ажилладаг connector гэж тооцогдохгүй. API, лиценз, robots, экспорт, хандалтын нөхцөл, бодит хариуг эх сурвалж тус бүрээр шалгана.
ХУР/ДАН нь гэрээ, эрх шаарддаг. Хувийн мэдээллийг нийтийн индексэд оруулахгүй.
QPay зэрэг төлбөрийн connector нь энэ хайлтын эхний хувилбарын хүрээнд орохгүй.

## 4. Эх сурвалжийн бүртгэл ба холболт
Source: нэр, эзэмшигч, canonical URL, баримтжуулалт, төрөл (API/web/file/webhook),
хандалт (public/key/contract), ашиглах ба түгээх нөхцөл, шалгасан огноо,
төлөв (candidate/verified/active/degraded/blocked), шинэчлэлтийн хуваарь.
Бодит fetch ба schema шалгалт амжилттай болсон connector-ийг л active болгоно.
API adapter болон зөвшөөрөгдсөн web adapter ижил normalized document загварт өгөгдөл нийлүүлнэ.
Generic URL connector нь зөвшөөрөгдсөн domain, size/time limit, redirect validation-тай; private network руу хандахгүй.

## 5. Баримт, файл боловсруулах
PDF, DOCX, XLSX, CSV, TXT, HTML; скан PDF/зурагт OCR.
ZIP эхний хувилбарт татаж задлахгүй. Macro, script, executable ажиллуулахгүй.
Импортын 50 MiB хязгаар; OCR 100 хуудас хүртэл; давсан файлыг тодорхой алдаатай буцаана.
Файл: hash, MIME, хэмжээ, эх URL, татсан огноо, гарчиг, байгууллага, нийтэлсэн/баталсан огноо.
Эх файл зөвшөөрөгдвөл өөрчлөлтгүй хадгална. Текстийг хуудас/заалт/хүснэгтийн байршилтай индексжүүлнэ.
Ижил byte hash давхардлыг нэгтгэнэ; өөр байгууллагын ижил нэртэй баримтыг автоматаар нэгтгэхгүй.
OCR confidence болон OCR хийсэн эсэхийг үр дүнд харуулна.

## 6. Эрх зүйн актын мэдээлэл
Дугаар, баталсан байгууллага, баталсан огноо, хүчин төгөлдөр болох огноо,
хүчинтэй/хүчингүй/үйлчлэл зогссон/тодорхойгүй төлөв, нэмэлт өөрчлөлт, холбоотой актыг хадгална.
Эх сурвалж өгөөгүй огноо, төлөвийг таамаглахгүй.
Шинэ ба хуучин хувилбарыг тусдаа хадгалж current pointer ашиглана.
Өмнөх хувилбар болон эх сурвалжийн шинэчлэлтийг харуулна; баталгаажаагүй хувилбарыг одоогийн хууль гэж зарлахгүй.

## 7. Нэгдсэн хайлт
PostgreSQL full-text + pg_trgm, Unicode normalization; эх текстийг хадгална.
Кирилл Монгол хайлт, яг хэллэг, актын дугаар, байгууллага, огноо, төрөл, төлөв, файл, газар нутгийн шүүлтүүр.
Латин галигийг нэмэлт query expansion болгон хэрэглэж, яг таарсан кирилл/дугаарын үр дүнг эхэнд эрэмбэлнэ.
Гарчиг, дугаар, байгууллага, агуулгын таарцыг жинлэнэ.
Keyword search нь AI түлхүүргүй ажиллана. Semantic search/RAG нь дараагийн өргөтгөл.
Snippet нь баримтын бодит текстээс үүснэ. Үр дүн бүр эх URL, байрлал, хувилбар, татсан огноотой.
Алдаа гарсан эх сурвалж болон хамгийн сүүлд шинэчилсэн хугацааг хэрэглэгч харна.

## 8. Таталт ба экспорт
Эх файл татах; эх файл байхгүй бол эх вэбийг нээх болон систем үүсгэсэн TXT/CSV экспорт.
Системийн экспорт нь албан ёсны эх файл биш гэдгийг тэмдэглэнэ.
Сонгосон үр дүнг CSV/JSON экспорт; зөвшөөрөгдсөн эх файлуудыг ZIP багцаар татах.
ZIP нь хамгийн ихдээ 100 файл, нийт 250 MiB. Амжилтгүй файлуудыг manifest-д тусгана.
Эх файл татах эрхгүй бол товчийг идэвхгүй болгож эх холбоосыг харуулна.

## 9. Автомат шинэчлэлт ба webhook
Хуваарьт sync, ETag/Last-Modified, timeout, backoff, retry, per-source rate limit.
Сүүлийн амжилттай индексийг алдаа гарсан ч хадгална. Jobs идемпотент, checkpoint-той.
Хадгалсан хайлтад шинэ эсвэл өөрчлөгдсөн баримт таарвал outbound webhook.
HMAC signature, event ID, timestamp, retry, delivery log; at-least-once delivery.
Webhook URL-д мөн SSRF хамгаалалт хэрэглэнэ. Эхний хувилбарын webhook нь хэрэглэгчийн системд мэдээлэл дамжуулах зориулалттай.

## 10. Архитектур
React + TypeScript frontend; FastAPI backend; PostgreSQL; Redis job queue;
worker; S3-compatible object storage. Docker Compose local setup.
Modules: source registry, ingestion adapters, extraction, indexing/search,
document/download service, saved-search/webhook, auth/admin.
API: GET /sources, GET /search, GET /documents/{id}, GET /documents/{id}/versions,
GET /documents/{id}/download, POST /imports, POST /saved-searches,
POST /webhook-subscriptions; admin-only POST /sources/{id}/sync.
Search response: hits, facets, pagination, indexed_at, source coverage/staleness.
Secrets сервер дээр; UI/API логт түлхүүр харуулахгүй.

## 11. Байгууллагын эрх ба хамгаалалт
Public document болон private tenant document тусгаарлана.
Tenant ID-г серверийн session-оос тогтооно; client өгсөн утгад итгэхгүй.
Download, search, export бүгд ижил ACL шалгана. Admin, editor, viewer эрх.
Audit log: импорт, source өөрчлөлт, таталт, webhook тохиргоо.
Upload quarantine, file-type validation, parser isolation, limit, malware scan hook.
Нийтийн эх сурвалж импортлох эрх ба файлыг дахин түгээх эрхийг тусад нь хадгална.

## 12. Хэрэгжүүлэлтийн дараалал
A. Нийтийн суурь хайлт: source registry, verified NSO adapter, generic file import,
extraction, keyword search, filters, source citations, original download, Docker.
B. Legalinfo болон бусад сайт: нөхцөл/интерфейсийг шалгаж зөвшөөрөгдсөн adapter,
legal metadata, versioning. Хандалтгүй эх сурвалж candidate хэвээр байна.
C. Saved searches, scheduled sync, signed outbound webhook, export bundles.
D. Tenant/private import, ACL, audit, optional semantic search.
Эдгээр үе шатууд нэг интерфейстэй; үе шат бүрийн бодит coverage-ийг харуулна.

## 13. Хүлээн авах шалгалт
- Монгол хайлт PDF/DOCX/XLSX/CSV-ийн бодит импортолсон агуулгыг олдог.
- Огноо/төрөл/байгууллага/төлөвийн шүүлтүүр хослон ажилладаг.
- Татсан эх файлын SHA-256 нь импортолсон эхтэй адил.
- Баримтгүй хайлт зохиомол үр дүн үүсгэдэггүй.
- Source алдаа нь coverage/staleness-д харагдаж, хуучин индекс устдаггүй.
- Хүчингүй/тодорхойгүй актын төлөв хүчинтэй мэт харагддаггүй.
- Дахин sync хийхэд давхар баримт/notification үүсэхгүй.
- Tenant хооронд хайлт, таталт, экспорт, webhook мэдээлэл алдагдахгүй.
- SSRF, oversized file, хортой archive, parser timeout хамгаалалтыг шалгана.
- UI loading/empty/error/download disabled төлөвтэй; keyboard болон mobile ашиглалттай.
- Fixture шалгалт болон live connector smoke test-ийг ялгаж тайлагнана.

## 14. Хязгаар, review
Нийтийн веб харагдах нь API эсвэл дахин түгээх зөвшөөрөл гэсэн үг биш.
Техникийн endpoint, credentials, эрх тодорхойгүй эх сурвалжийг идэвхтэй гэж үзүүлэхгүй.
Live coverage, OCR чанар, галиг хайлтын чанарыг хэмжиж тайлагнана.
Энэ загварыг хянаж баталсны дараа нарийвчилсан хэрэгжүүлэх төлөвлөгөө гаргана.
